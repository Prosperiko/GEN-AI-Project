# AI Document Intelligence Engine

An intelligent document processing backend built during the Incubator Hub program. This project extracts, processes, and queries information from complex, image-heavy PDFs using advanced Optical Character Recognition (OCR) and Retrieval-Augmented Generation (RAG). To ensure data privacy and flexible usage, it implements a secure "Bring Your Own Key" (BYOK) architecture for OpenAI integration.

## ✨ Key Features

* **Bring Your Own Key (BYOK):** Users provide their own OpenAI API keys, ensuring strict control over token usage and data privacy.
* **Advanced OCR Pipeline:** Accurately parses and extracts text from scanned, image-heavy PDF documents.
* **RAG-Powered Querying:** Enables semantic, context-aware conversational search across uploaded documents.
* **Scalable Backend:** Structured to serve as a reliable API for document intelligence applications.

## 🛠️ Tech Stack

* **Language:** Python
* **AI & NLP:** OpenAI API, RAG Architecture
* **Document Processing:** OCR integration
